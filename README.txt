Homestead Seasons v1.9

New in this release:
- Automatic current weather + 3-day forecast using Open-Meteo (no API key required)
- Optional weather note attachment when recording an observation
- Species/plant identification assistance using iNaturalist taxonomy search
- Seasonal prompts based on your own prior-year observations plus a monthly homestead prompt
- Existing cloud sync, photos, Life profiles, Property map, Seasons, and Year in Review remain intact

Weather location is saved only on the device where you set it. The app asks the browser for location permission when you tap Use Current Location.
Identification suggestions are aids, not guaranteed identifications; confirm a match before saving it.
Seasonal prompts are in-app prompts shown when you open Homestead Seasons. They are not background push notifications.
