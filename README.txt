Homestead Seasons v1.8 — Polish & Stability

Changes in this build:
- Larger, iPhone-friendly touch targets and 16px form controls to prevent unwanted Safari zoom.
- Stronger safe-area and viewport handling.
- Safer recovery if local cached JSON becomes malformed.
- More resilient service-worker installation and fresher JS/CSS updates.
- Account panel now shows connection state, last sync time, and queued changes.
- Sync refresh is throttled when returning to the app, reducing duplicate refreshes.
- Authentication state handling is more resilient to sign-out/token changes.
- Accessibility improvements for focus states and close buttons.
- Reduced-motion support.

No database/schema changes are required.
