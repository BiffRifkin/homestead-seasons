Homestead Seasons v1.4 — Photo Handling

New in this build:
- Up to 8 photos per observation
- Separate Take Photo and Choose Photos controls for iPhone/iPad
- Multiple-photo cloud storage in Supabase
- Upload progress shown in the cloud status chip
- Photo thumbnails in Journal and Life
- Tap any photo to view it full-screen
- Remove individual photos while editing an observation
- Photo galleries in Life profiles and Year in Review
- Existing single-photo observations remain compatible

Upload all files in this folder to the existing GitHub repository root and commit the changes. GitHub Pages will keep the same address.


v1.4.1: Photo controls are now two explicit full-width buttons: Take a Photo and Choose Existing Photos.
